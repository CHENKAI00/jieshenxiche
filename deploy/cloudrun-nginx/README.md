# 云托管 https 入口（免备案方案 C）

一个 20 行的 nginx 容器：云托管给它一个**已备案的 https 域名**，它把请求反代到你现有的
`27.124.46.63:8099`。小程序不用改代码，只把地址换成这个 https 域名。

```
小程序 ──https──> xxx.run.tcloudbase.com（本容器 nginx） ──http──> 27.124.46.63:8099（现有后端）
```

## 方式一：微信云托管（控制台在微信公众平台）

1. 微信公众平台 → 左侧「云托管」→ 开通（需要小程序已完成微信认证）
2. 新建环境（按量计费，选上海/广州，实例数可缩容到 0）
3. 新建服务 `jieshen-proxy` → 部署方式选「代码包/本地代码」→ 上传**本目录**（含 Dockerfile）
   - 端口填 `80`
   - 实例规格选最小（0.25 核 0.5G）
   - 最小实例数 0、最大 1（没人用时不计费）
4. 部署完成，控制台会给出默认域名，形如 `jieshen-proxy-xxxx.sh.run.tcloudbase.com`
5. 验证：浏览器打开 `https://该域名/health`，应返回 `{"ok":true,...,"db":"up"}`
6. 微信公众平台 → 开发管理 → 开发设置 → 服务器域名：
   - request 合法域名：`https://该域名`
   - uploadFile 合法域名：`https://该域名`
7. 小程序 → 身份页底部「服务器」改成该域名（或改 `app.js` 默认 baseUrl 后重新上传）

## 方式二：腾讯云 CloudBase 云托管（不需要小程序认证）

1. 注册腾讯云并实名 → 打开 https://console.cloud.tencent.com/tcb → 新建环境（按量计费）
2. 云托管 → 新建服务 → 上传本目录代码包 → 端口 80 → 部署
3. 其余同上：拿 https 域名 → 加到小程序合法域名 → 小程序里改服务器地址

## 注意

- 冷启动：实例缩容到 0 后，第一个请求要等 1–3 秒（小程序首屏会有一次慢请求）
- 流量费按量，洗车店这种访问量基本忽略；想更稳可设最小实例数 1（费用约个位数/月）
- 换后端地址：改 `nginx.conf` 里的 `proxy_pass`，重新部署一次
- 后端若开 HTTPS 或换端口，同步改这里
- 上传识别图片走的是同一个域名（`/api/v1/ocr/*`），`uploadFile` 合法域名别忘配
